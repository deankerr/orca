# Reading product documentation

- Start with the document owning the product area; dated studies in `docs/evidence` support its maintained conclusions.
- Read a cited study's `README.md` when investigating the evidence behind a decision.
- Open only the CSVs or scripts needed for the question; do not load entire study directories for completeness.
- Treat study measurements as dated observations, not claims about the current production population or implementation.
- Use UTC when interpreting study dates; a date without a qualifier is already UTC.
- Reading documentation or evidence alone requires neither orca-docs nor orca-data-study.
- Use orca-docs for documentation changes and orca-data-study for conducting or restructuring production-data studies.
