# OpenRouter observations

Record upstream evidence here; keep ORCA policy in `docs/orca/` and link to it.
Each note owns one subject. Keep field facts with the field and relationships in
one place. Move long investigations and corpus tables into `appendix/`.

- State known behavior directly; record uncertainty when it changes a decision.
- Scope measurements by date, population, and denominator.
- Preserve upstream field names, terminology, and exact decimal values.
- Property frequency alone does not establish operational or economic importance.
- Update conclusions when new evidence contradicts them.

Use markers only when they affect interpretation: ⚠️ trap, 🔄 volatile,
📊 measurement, ❓ unresolved, 💤 outside current scope.
