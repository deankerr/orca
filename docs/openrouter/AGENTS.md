# OpenRouter

This directory documents OpenRouter as observed through its APIs.

## Documentation standard

Each note owns one subject. Prefer a new focused note over adding an unrelated section to an
existing one.

Separate these kinds of statements:

- **Semantics** are supported by API behavior or primary documentation.
- **Observed** facts are empirical and include the corpus or observation date.
- **Unknowns** remain explicit; do not turn a plausible interpretation into a fact.

Use evidence markers sparingly:

- 📌 — important verified observation
- ⚠️ — trap, exception, or context-sensitive interpretation
- ❓ — unknown or unconfirmed semantics
- 🔄 — volatile value rather than durable entity state

Preserve upstream field names in backticks. Use OpenRouter's public terminology where it exists,
and define any local analytical term on first use.
